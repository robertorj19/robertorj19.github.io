Collaborative Spotify Playlist Generator

JavaScript • Python • Spotify API

Tired of arguing over the aux at parties, I built a bot that turns music selection into a democratic game. Comic Book Recommender System

Java • Python • Machine Learning • Full Stack

My final-year dissertation project: a full-stack AI-powered web application designed to introduce users to comic books they didn't know they'd love. I engineered a custom hybrid filtering algorithm in Java, trained on curated comic metadata and user preference patterns. The system learns granular preferences across artist, author, decade, genre, and publisher, then surfaces serendipitous yet accurate recommendations. From data selection and preprocessing through the entire backend pipeline using custom pandas implementations, to a secure login system and responsive frontend—I built it from scratch. The emphasis is on discovery over popularity. Available to view upon request.
